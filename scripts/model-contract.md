# Контракт интерактивных моделей

Модели — классические browser JS scripts, также исполнимые Node vm; без import/export и внешних зависимостей. Каждый файл добавляет объекты через `globalThis.LAB_MODELS = (globalThis.LAB_MODELS || []).concat([...])`.

Объект:

```js
{
  id: 'surplus', group: 6,
  title: 'Рабочий день и прибавочная стоимость',
  description: 'Короткое понятное пояснение.',
  formula: String.raw`m=\lambda(T-t_n)`,
  formulaIds: ['F034','F037'], // реально рассчитываемые отношения
  relatedIds: ['F039'], // только связанные положения, честно отмеченные как справочные
  fields: [{key:'hours', label:'Рабочий день', symbol:'T', unit:'ч', value:12, min:1, max:24, step:0.5, hint:'...'}],
  presets: [{label:'Пример Маркса', values:{hours:12}}],
  compute(p) {
    return {
      metrics: [{key:'surplus',label:'Прибавочная стоимость',value:3,unit:'ден. ед.',hint:'...'}],
      bars: [{label:'Необходимый труд',value:6,color:'blue'},{label:'Прибавочный труд',value:6,color:'red'}],
      barUnit:'ч',
      table: {columns:['Показатель','Значение'],rows:[['A', 12]]},
      flow: ['Д = 500','Т: средства и рабочая сила','Производство','Д′ = 590'],
      notes: ['Явные предпосылки и ограничения.'],
      warnings: ['Только при действительно нарушенном условии.']
    };
  },
  plot: {x:'hours',y:'surplus',label:'Как продолжительность труда влияет на прибавочную стоимость'}
}
```

`value` в metrics — число либо null (не определено), никогда NaN/Infinity. Проценты — числа 20, а не 0.2, unit '%'. Все поля числовые; min/max — допустимые пределы интерфейса. Пустые/нечисловые поля проверяет UI, cross-field ограничения проверяет compute (вернуть warnings и null там, где формула не определена; не зажимать молча исходные значения). Показать отрицательные остатки как дефицит, не спрятать. bars только неотрицательные разлагаемые величины; несравнимые величины/единицы не объединять. Функция без мутаций и побочных эффектов.

У каждой модели минимум 2 metrics, 1 plot и 1 preset. Дополнительные поля в compute можно опускать. Числа в table могут быть строками с единицами; они не интерпретируются как HTML. Источники и полный текст подтягиваются из каталога по F-ID. Не выдавать учебную параметризацию за буквальную авторскую формулу. Можно группировать несколько связанных формул в одной модели.
