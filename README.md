# Лаборатория формул Маркса и Энгельса

[Открыть стенд на GitHub Pages](https://idlesign.github.io/marx-formulas/)

Учебный стенд по каталогу формул Маркса и Энгельса: **41 численная модель, 14 тем, 101 пункт каталога и 7 переводческих примечаний**. Он позволяет менять предпосылки, сравнивать сценарии и читать источники, определения переменных и математические оговорки.

**Граница исследования:** исходный каталог составлен по 42 цифровым копиям томов русского издания с выборочной, не сплошной сверкой MEGA. Полный корпус MEGA, в том числе все подготовительные рукописи, не обследован. Наличие пункта в стенде не означает, что все его варианты проверены по критическому изданию.

Численные модели — учебные параметризации, а не доказательство эмпирической истинности теории. **Не все 101 пункта и не все исторические варианты численно вычисляются.** Метка «Есть расчёт» связывает пункт с реально рассчитываемыми отношениями (`formulaIds`); «Связанный разбор» ведёт только к справочному тексту (`relatedIds`). У каждой модели перечислены условия применения. Отрицательные остатки не скрываются, а неопределённые отношения не заменяются нулём.

## Запуск без установки

Откройте [опубликованный стенд](https://idlesign.github.io/marx-formulas/) либо скачайте репозиторий и откройте [index.html](index.html) в современном браузере. Для скачанной копии сборка, установка пакетов и подключение к интернету не требуются: каталог, скрипты, шрифты и библиотеки находятся в этой папке. Для переноса стенда достаточно всей папки репозитория; исследовательские тома и исходный Markdown для просмотра не нужны.

Источники указаны библиографически: например, «Маркс, Энгельс. Сочинения, 2-е изд., т. 25, ч. I»; названия исследовательских файлов и ссылки на PDF не публикуются. Сохранены печатные страницы и, где они приведены, номера страниц цифровой копии. Внешние ссылки на текстовые страницы первоисточников открываются только по вашему нажатию и требуют интернета.

## Как проводить опыт

1. Выберите тему и модель. Прочитайте формулу, единицы измерения и предпосылки.
2. Задавайте значения полями или ползунками. Десятичный разделитель — точка либо запятая. Пустой ввод, нечисловое значение и выход за диапазон останавливают расчёт, а не сохраняют на экране старый результат.
3. Сравнивайте показатели с исходным сценарием. Текущие правки не меняют базу сравнения: её можно отдельно закрепить из текущих значений либо восстановить из неё поля.
4. Выбор готового примера **заменяет и текущие значения, и исходную базу сравнения**. Сброс модели возвращает её заводской пример.
5. Выберите входной параметр по горизонтали и показатель по вертикали графика. Названия величин и единицы измерения подписаны у осей; подписи меняются вместе с выбором. Для каждой из двух линий изменяется только выбранный вход; остальные параметры фиксируются соответственно на текущих или исходных значениях. Это условная зависимость при прочих равных, а не автоматически рассчитанная историческая траектория. Числа доступны и в таблице под графиком.
6. Откройте связанный пункт каталога: там сохранены текст формулы, варианты в разных работах, ссылки на источники и отдельная оценка математических противоречий. У каждого пункта есть краткий контекст его появления. В каталоге доступны поиск, фильтры тем и оценок E, сортировка «Сначала E5» и переводческие примечания.

Пределы `min`/`max` у ползунков — **технические границы учебного интерфейса**, не универсальные экономические законы. Некоторые комбинации внутри этих пределов всё равно нарушают условия модели: такие случаи сопровождаются предупреждениями. «Не определено» означает отсутствие результата при данных условиях, а не нулевую величину. Числа округляются для показа; расчёт выполняется с точностью JavaScript `Number`.

## Оценки E0–E5

Шильдик рядом с номером формулы относится к наиболее проблемному реально приведённому варианту, а не автоматически к основной формуле или автору. E0 — математических проблем не выявлено; E1 — оговорка точности/обозначений; E2 — неоднозначность; E3 — неполнота; E4 — условная несовместимость; E5 — конкретная неверная арифметика, знак или размерность. Полная шкала открывается из каталога. Для всех ненулевых оценок рядом с шильдиком постоянно показана атрибуция, а в карточке — пояснение, к чьей посылке или какому воспроизведению относится балл. Это не скрытая подсказка по наведению. Перед формулой отдельно указан статус показанной записи: исправление Маркса может иметь E0, хотя отвергнутый им вариант Смита или Прудона получает E5. Намеренное доведение Энгельсом посылки до абсурда не обозначается как его вычислительная ошибка. Объект и основание оценки также сохранены в полном тексте.

Это не вероятность ошибочности теории. Ошибка оппонента, дефект воспроизведения и проблема собственно авторского расчёта различаются. Непроверенный аппарат MEGA сам по себе не повышает балл.

Новые расчёты по дополнительной сверке: производительность и относительная прибавочная стоимость в «Grundrisse» (F040); капитализированный ремонт и разночтение 306/307 (F048); квартера и бушели в примере ренты (F081). Исторические строки отделены от расчётов с изменяемыми пользователем условиями.

## Сохранение и ссылки

- Сценарии каждой модели, база сравнения и оси графика сохраняются в `localStorage` этого браузера под ключом `marx-lab-v1`, если браузер разрешает хранилище. Отправки данных и аналитики нет, учётная запись не требуется. При запрете хранилища стенд работает без сохранения между посещениями.
- Хранилище зависит от браузера и адреса страницы. Опубликованный стенд и скачанная копия имеют отдельные сохранения. При переносе папки прежние сохранения могут быть недоступны.
- Кнопка ссылки на сценарий копирует URL с фрагментом `#lab/...`: в нём находятся текущие числа, исходные числа сравнения и оси графика. Если буфер обмена недоступен, адрес показывается для ручного копирования. Ссылка может раскрыть эти данные тому, кому вы её передадите.
- Ссылкой на сценарий в GitHub Pages можно поделиться напрямую. При открытии скачанной копии ссылка содержит путь к файлу на вашем компьютере: передайте также папку стенда и замените часть до `#` на путь к другой копии `index.html`, сохранив фрагмент.
- Ссылки `#formula/F...` и `#formula/TR-...` открывают конкретный пункт или переводческое примечание.

## Публикация и проверки

В корне репозитория находится готовый статический стенд. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll. Сборка и внешние зависимости для просмотра не нужны.

Проверка синтаксиса и самостоятельные тесты моделей, графиков и интерфейса (нужен современный Node.js):

```bash
node --check app.js
node --test tests/advanced.test.cjs tests/assessments.test.cjs tests/audit.test.cjs tests/chart.test.cjs tests/foundations.test.cjs tests/grundrisse.test.cjs tests/integration.test.cjs tests/interface.test.cjs
```

`catalog.js` содержит готовый каталог. Исследовательский Markdown `0formulas.md` и исходные PDF в этот репозиторий не входят. Скрипт `scripts/build-catalog.py` и тест `tests/catalog.test.cjs` сохранены из исследовательского проекта: им нужен исходный Markdown и его прежняя структура каталогов, поэтому в команду самостоятельных проверок выше этот тест не включён.

Контракт для расширения моделей описан в [scripts/model-contract.md](scripts/model-contract.md). Тесты не заменяют историческую проверку первоисточников и визуальную проверку интерфейса.
